# Select

A native macOS menu-bar utility. Select text anywhere — or copy an image — and a compact,
Raycast-style launcher pops up next to it with content-aware actions: copy, multi-clip queue,
paste into another app, save to Apple Notes or a Markdown vault, OCR, and AI actions
(translate / summarize / rewrite / fix grammar).

Built with native SwiftUI + AppKit. Direct distribution only (not sandboxed).

## Requirements

- macOS 14 (Sonoma) or later. On-device AI (Apple Foundation Models) and future Liquid Glass
  styling light up on macOS 26+.
- Full Xcode to build.

## Build & run

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
`project.yml`. A pre-generated `SelectApp.xcodeproj` is committed, so you can just open it:

```bash
open SelectApp.xcodeproj
```

Then press Run (⌘R). On first launch:

1. The onboarding wizard asks for **Accessibility** permission — grant it in
   System Settings → Privacy & Security → Accessibility. This is required to read selected text
   and to paste into other apps.
2. Choose a trigger mode (Automatic / Hotkey / Both). The default hotkey is **⌥C**.
3. Saving to Apple Notes will prompt for **Automation** permission the first time.

To regenerate the project after changing `project.yml` or adding files:

```bash
xcodegen generate
```

### Command-line build

```bash
xcodebuild -project SelectApp.xcodeproj -scheme SelectApp -configuration Debug \
  -destination 'platform=macOS' -derivedDataPath ./.build/DerivedData build
```

## How it works

- **Selection trigger** (`SelectionMonitor`): a global `leftMouseUp` monitor + Accessibility read
  (`AXSelectedText`), with debounce, minimum-length, secure-field, and cooldown safeguards.
- **Image trigger** (`ClipboardMonitor`): watches `NSPasteboard.changeCount` for copied images.
- **Hotkey** (`HotkeyManager`): Carbon `RegisterEventHotKey`; covers keyboard selections too.
- **Launcher** (`LauncherPanel` / `PanelController`): a non-activating floating `NSPanel` that
  takes keyboard input without deactivating the source app, so replace-in-place works. Shows a
  peek bar that expands into the full launcher.
- **Actions** (`ActionRegistry`): content-aware list (text vs image).
- **AI** (`AIService` / `ProviderRouter`): BYOK for OpenAI, Anthropic, Gemini, and any
  OpenAI-compatible endpoint (keys in Keychain); on-device Apple Foundation Models default.
- **Save targets**: Apple Notes (AppleScript) and Markdown vault (security-scoped bookmark).
- **OCR** (`ImageService`): Apple Vision `VNRecognizeTextRequest`, on-device.

## Not yet wired (scaffolded)

- **Auto-updates**: `UpdaterController` is a stub. Add the Sparkle SPM package and point it at a
  signed appcast to enable in-app updates. See `scripts/release.sh`.
- **Licensing**: `LicenseManager` stores/activates a key with a placeholder check. Wire it to your
  store (Gumroad / Lemon Squeezy / Paddle) or offline signature verification.
- **Liquid Glass**: `GlassBackground` currently uses the `NSVisualEffectView` material fallback;
  add the macOS 26 `.glassEffect()` path when targeting 26+.

## Release

See `scripts/release.sh` for the archive → sign (Developer ID) → notarize → `.dmg` flow. Requires
an Apple Developer Program membership (only at release time).

## Project layout

```
SelectApp/
  App/         App entry, AppDelegate (status item), AppCoordinator
  Selection/   Selection + accessibility + hotkey
  Clipboard/   Clip queue, pasteboard, paste-into-app
  Save/        Apple Notes + Markdown vault
  Image/       Vision OCR
  AI/          Providers, router, service, Keychain, prompts
  Actions/     Action protocol + registry + concrete actions
  UI/          Panel, launcher views, settings, onboarding
  Settings/    AppSettings
  Licensing/   LicenseManager (scaffold)
  Updates/     UpdaterController (scaffold)
  Models/      CaptureContent
  Resources/   Info.plist, entitlements, assets
```
